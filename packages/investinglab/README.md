# investinglab

Núcleo de **InvestingLab**: una librería Python pura (sin API ni base de datos) para ingerir
datos de mercado de múltiples fuentes, modelarlos como objetos de dominio inmutables, analizar
carteras, simularlas con Monte Carlo y generar informes.

Se usa igual desde un notebook que desde la API de la plataforma. La documentación completa
está en el [README del repositorio](../../README.md).
