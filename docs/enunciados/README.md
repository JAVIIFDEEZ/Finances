# Enunciados

Los enunciados y el material de clase del máster están protegidos por derechos de autor y
**no se versionan**. Esta carpeta está ignorada por git (salvo este fichero): guarda aquí tus
copias locales, por ejemplo `docs/enunciados/B1-T1.pdf`.

Lo que sí se versiona es la **matriz de trazabilidad** de cada módulo, redactada por nosotros,
en `docs/modules/<módulo>/`.
